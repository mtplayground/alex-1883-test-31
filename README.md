# alex-1883-test-31

A minimal Vite app.

## Requirements

- Node.js 20
- npm

## Development

```bash
npm install
cp .env.example .env
npm run dev
```

Open the local URL printed by Vite to view the hello page.

## Environment

- `VITE_DEV_SERVER_PORT`: optional local development server port.
- `VITE_APP_TITLE`: public browser-facing app title read from `import.meta.env`.

## Build

```bash
npm run build
```
